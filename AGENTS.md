# Contributing agents — MineShelt

This repository is an instructional Agent Skill, not Minecraft mod source code and not a structure generator.

1. Preserve the vendor-neutral skill in mineshelt/SKILL.md with valid Agent Skills frontmatter and progressive disclosure.
2. Changes must improve **intentional architectural decisions and honest verified execution**, not increase random decoration or produce automated prefab variants.
3. Do not claim to have entered a world, viewed screenshots, used an editor, compiled a mod, or verified a structure without evidence.
4. When describing mod integration, avoid fabricated API calls and broad promises across incompatible loaders/versions. Inspect the actual repository and mappings.
5. Examples must explain *why* each decision exists. Refrain from reusing a single fixed house geometry for every biome.
6. Keep heavy subject matter in mineshelt/references/ and keep the core SKILL.md concise and imperative.
7. Amend tests/scenarios.md whenever behavior expectations change. Evaluate qualitative outputs using references/critique-and-verification.md.
8. Respect original saves, player structures, spawn logic, performance requirements, world protection, and project license.
9. Prefer practical build evidence and revisions over inflated self-assigned quality scores.

Definition of done for changes to this repository: valid frontmatter, all relative links resolved, instructional consistency, no generator creep, documented user-facing behavior, and scenario coverage.
